Über dieses Projekt

Universal Translator ist eine Browser-Erweiterung, die fremdsprachige Texte auf Webseiten erkennt und ins Englische übersetzt. Sie ermöglicht es den Benutzern, sowohl den Originaltext als auch die englische Übersetzung gleichzeitig zu sehen.

Die Originalformatierung und Verlinkungen wie dieser Link zu weiteren Details bleiben dabei vollständig erhalten.

Wichtige Funktionen

  • Automatische Spracherkennung und Übersetzung
  • Wiederherstellung des Originaltextes per Mausklick
  • Schutz von sensiblen Formularfeldern und Codeblöcken

Code-Erhaltungstest

Der folgende Programmcode darf vom Übersetzer NICHT verändert werden:

function berechneSumme(a, b) {
    // Dies ist ein Kommentar im Code
    return a + b;
}
